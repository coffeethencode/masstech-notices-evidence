# `docs/legal/` — reference material, **not evidence**

Everything under `docs/legal/` is secondary research: case files, doctrine
notes, statutory summaries. It exists so that a session picking up this
repository has the legal frame in hand without re-deriving it.

**It is categorically outside the chain of custody.**

| | `artifacts/` + `manifests/` | `docs/legal/` |
|---|---|---|
| Content-addressed by SHA-256 | yes | no |
| OpenTimestamps / RFC 3161 anchored | yes | no |
| Append-only, never rewritten | yes | **no — edit freely** |
| Admissible as a record of what MassTech posted | that is the point | no |

Nothing in this directory should ever be cited as proof of *what MassTech
posted, or when*. That claim rests only on the hashed, timestamped artifacts
and their manifest lines. Notes here are a reading aid and may be wrong,
stale, or superseded — each file carries its own verification status.
